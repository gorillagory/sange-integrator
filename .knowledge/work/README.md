# Work Queue Flow (Mandatory)

This folder is the execution ledger. Use it for all implementation phases.

## Required Steps

1. Create a checklist in `.knowledge/work/working` using:
   - `(taskname)-(tasknumber)-checklist.md`
2. Add concrete, verifiable checklist items (not vague tasks).
3. Execute items in order and update status progressively.
4. Record verification outcomes and blockers in the same checklist.
5. Set checklist header status to `completed` only after all items are done.
6. Move checklist file to `.knowledge/work/completed`.
7. Rename the completed artifact to `NN-History-<taskname>.md` so the folder sorts oldest-first.

## Rule

If a checklist is still in `working`, that phase is not done.
